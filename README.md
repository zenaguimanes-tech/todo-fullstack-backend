# 📋 To-Do List Fullstack - Backend (Flask)

Une API REST simple et légère pour gérer des tâches, développée avec Flask.

## 🔗 API en ligne

- **URL** : `https://todo-fullstack-backend-9gf7.onrender.com`
- **Endpoint** : `/api/tasks`

## ✨ Fonctionnalités

- ✅ Récupérer toutes les tâches (GET)
- ✅ Ajouter une tâche (POST)
- ✅ Modifier une tâche (PUT) - texte, date, ou statut
- ✅ Supprimer une tâche (DELETE)
- ✅ Stockage dans un fichier JSON
- ✅ CORS configuré pour Vercel

## 🛠️ Technologies utilisées

- **Python 3** : Langage
- **Flask** : Framework web
- **Flask-CORS** : Gestion CORS
- **Gunicorn** : Serveur de production
- **Render** : Hébergement
